# Modular Monolith vs Gateway

This is the code from my talk @ .net conference 2025, hold in Milan the 28/11/2025.
To test the code please create a database with the included script and change the connection string.

## How to use

To test the modular monolith, please launch run-modular-monolith.bat, or, if you want to debug, lauch with VS debug.
To Test api and gateway, please lauch run-apis.bat and run-gateway.bat.
